## 💻 Instalación

### Requisitos Previos
- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Servidor web local (opcional para desarrollo)
- Editor de código (VS Code recomendado)

### Paso 1: Clonar o Descargar

```bash
# Clonar repositorio
git clone https://github.com/Auditorexchile/Sistema_Conecta_ERP.git

# O descargar ZIP y extraer
```

### Paso 2: Agregar Imágenes

Consulta el archivo `IMAGENES_REQUERIDAS.md` para la lista completa de imágenes necesarias.

1. Crea la carpeta `assets/img/` si no existe
2. Agrega todas las imágenes requeridas con los nombres exactos
3. Optimiza las imágenes para web

### Paso 3: Servidor Local (Opcional)

```bash
# Opción 1: Python
python -m http.server 8000

# Opción 2: Node.js (npx)
npx serve

# Opción 3: PHP
php -S localhost:8000

# Opción 4: VS Code - Live Server extension
```

### Paso 4: Abrir en Navegador

```
http://localhost:8000
```

## 🔧 Mantenimiento

### Actualizar Contenido
1. Edita `index.html` para cambiar textos
2. Edita `assets/css/modern-style.css` para estilos
3. Edita `assets/js/modern-app.js` para funcionalidad

### Agregar Nuevos Servicios
1. Duplica un `service-card` en `index.html`
2. Actualiza el contenido
3. Agrega el item al menú de navegación dropdown

### Optimización
```bash
# Minificar CSS
npx clean-css-cli -o assets/css/modern-style.min.css assets/css/modern-style.css

# Minificar JS
npx terser assets/js/modern-app.js -o assets/js/modern-app.min.js

# Optimizar imágenes
npx imagemin assets/img/* --out-dir=assets/img/optimized
```
